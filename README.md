# Lula Light

A light Omarchy theme with warm rose-paper surfaces, deep wine text and a restrained red accent.

![Lula Light preview](preview.png)

Its dark sibling is [Lula](https://github.com/PedroAugustoOK/omarchy-lula-theme).

## Install

```bash
omarchy theme install https://github.com/PedroAugustoOK/omarchy-lula-light-theme
omarchy theme bg next
```

The first command installs and applies the theme. The second cycles through its wallpapers.

## Included

- `colors.toml` — the theme palette.
- `backgrounds/` — the included wallpapers.
- Root-level appearance files for Omarchy and the supported applications.
- `preview.png` — theme artwork.
