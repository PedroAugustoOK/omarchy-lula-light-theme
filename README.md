# Lula Light

![Lula Light theme preview](preview.png)

A light Omarchy theme with warm rose paper, deep wine text and a readable red accent. The preview is palette artwork, not a desktop screenshot.

[**Lula**](https://github.com/PedroAugustoOK/omarchy-lula-theme) is the dark sibling, with wine-black surfaces and warm text.

## Install

```bash
omarchy theme install https://github.com/PedroAugustoOK/omarchy-lula-light-theme
omarchy theme bg next
```

Installation applies the theme. The second command cycles its three static backgrounds.

`colors.toml` is the palette source; Omarchy generates application configurations from its templates. The repository does not ship Lua, terminal configuration files or `vscode.json`.

Reapply, update, refresh after an Omarchy upgrade, or remove the theme with `omarchy theme set lula-light`, `omarchy theme update`, `omarchy theme refresh` and `omarchy theme remove lula-light`.
